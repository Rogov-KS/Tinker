# Инструкция по локальному запуску

Пререквизиты: [docker compose](https://docs.docker.com/compose/install/)

Находясь в корне проекта `final-project` надо запустить:
`docker compose down && docker compose up --build -d`

При это добавлять ли тестовых пользователей или нет решается с помощью переменной окружения `SEED_DB`
По дефолту она равна `true`. Чтобы поднять проект и не добавлять тестовых пользователей можно запустить команду:
`docker compose down && SEED_DB=false docker compose up --build -d`

Однако я замечу, что так как для бд в докер компоуз используется volume, то после первого запуска с тестовыми данными, эти тестовые данные сохраняются в volume.
А значит чтобы запустить сервис без тестовых данных придётся удалить соотвествующий volume из докер компоуз.
